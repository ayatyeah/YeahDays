# YeahDays

**«Tinder твоих действий»** — не habit tracker со списком из 50 задач,
а ежедневная подборка нескольких действий под твоё текущее состояние.

Приложение отвечает на один вопрос:
> Какое маленькое действие сегодня максимально приблизит меня к лучшей версии себя?

---

## Что изменилось в этой версии

| Было | Стало |
|---|---|
| Список задач на главной | **Tinder-колода**: свайп вправо — беру, влево — не сейчас |
| Задача = название + сложность | 7 параметров: category, difficulty, duration, energy, timePreference, impact, why |
| Нет рекомендаций | **Scoring-движок** + backend API под будущий ML |
| 3 стата (Тело/Разум/Дисциплина) | **4 стата**: Сила, Интеллект, Капитал, Стабильность |
| PNG-персонаж + гардероб | **3D-персонаж на Three.js**, тело — функция статов |
| 4 экрана | **5 экранов**: Home, Today, Calendar, Progress, Profile |

### Движок рекомендаций

```
taskScore = goalMatch + timeMatch + difficultyMatch + userHistory + freshness
```

| Компонент | Вес | Что учитывает |
|---|---|---|
| `goalMatch` | 0.30 | приоритеты пользователя + отставание стата + impact |
| `timeMatch` | 0.20 | время суток + бюджет минут |
| `difficultyMatch` | 0.25 | энергия сегодня vs требуемая |
| `userHistory` | 0.15 | принял / отклонил / довёл до конца |
| `freshness` | 0.10 | антиповтор показов |

Каждая карточка показывает **почему** её предложили — это строится
из максимального компонента скоринга.

### Подключение настоящего бэкенда

Контракт уже готов. Переключение — одна переменная:

```bash
NEXT_PUBLIC_ENGINE=remote npm run build
```

Тогда `fetchRecommendations()` пойдёт в `POST /api/recommendations`,
а свайпы начнут писаться в `POST /api/events` (обучающая выборка).
Если сеть упадёт — движок автоматически считает локально, экран
не остаётся пустым.

## 3D-персонаж

Тело собирается процедурно, пропорции — функция статов:

- **Сила** → шире плечи, объём груди, толщина конечностей, цветные дельты
- **Интеллект** → яркость светящегося ядра в груди и визора
- **Капитал** → золотые полосы на торсе, корона после 55%
- **Стабильность** → кольца платформы под ногами

Персонаж дышит, следит за пальцем, празднует выполнение задачи
(прыжок + вспышка ядра) и растёт при повышении уровня.
При отсутствии WebGL приложение продолжает работать.
