# YeahDays

Минималистичный трекер задач, где **в центре — человек, который эволюционирует с каждой выполненной задачей**. Тёмный фон, абстрактный серый персонаж по центру, 5 кнопок снизу.

Каждая задача даёт опыт (XP). XP → уровень → визуальная трансформация персонажа:

| Уровень | Веха | Что меняется |
|--------|--------|--------------|
| 1–19 | Пробуждение | маленькое серое тело |
| 20–49 | Сила | шире плечи, светлее |
| 50–99 | Форма | новый холодный цвет + аура |
| 100+ | Свет | сияние и лучи вокруг |

Персонаж непрерывно растёт (рост, ширина плеч, цвет) внутри тира, плюс «дышит» и покачивается (idle-анимация). При повышении уровня — оверлей с празднованием, при пересечении вехи — «Новая форма».

## Стек

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** — анимации персонажа, оверлеи, переходы
- **Zustand** (+ `persist`) — состояние и сохранение в `localStorage`
- **PWA** — `manifest.webmanifest` + service worker (офлайн, установка на домашний экран)

Данные сейчас живут в `localStorage` (local-first) — приложение запускается сразу, без БД и ключей. Бэкенд (PostgreSQL + Auth) — следующий шаг, см. ниже.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Прочие команды:

```bash
npm run build      # продакшн-сборка
npm run start      # запуск собранного приложения
npm run typecheck  # проверка типов (tsc --noEmit)
npm run gen-icons  # перегенерировать PNG-иконки из public/icon.svg
```

> ⚠️ Про типы: Next 16 гоняет собственную проверку типов при `build`, но она пока
> несовместима с нативным TypeScript 7 — поэтому в `next.config.ts` встроенный чек
> отключён (`typescript.ignoreBuildErrors`), а типы проверяются отдельно через
> `npm run typecheck` (проходит чисто). Как только Next добавит поддержку TS 7,
> флаг можно убрать.

## Категории и опыт

Задача относится к одной из трёх сфер, каждая качает свою характеристику:

- 💪 **Тело** — спорт, сон, еда
- 🧠 **Разум** — чтение, учёба, навыки
- 🎯 **Дисциплина** — рутина, работа, привычки

Опыт зависит от сложности: лёгкая +15, средняя +30, сложная +60 XP.

## PWA

- `public/manifest.webmanifest` + иконки (`icon.svg`, `icon-192/512.png`, maskable).
- `public/sw.js` — service worker: network-first для страниц, stale-while-revalidate для ассетов. Регистрируется только в проде.
- На странице «Аккаунт» есть кнопка установки (через `beforeinstallprompt`).

## Дальше: бэкенд (по плану)

Local-first MVP готов. Следующий шаг — синхронизация и вход:

1. **PostgreSQL + Prisma** — модели `User`, `Task`, `Stats`.
2. **API Routes** (`app/api/*`) — CRUD задач, начисление XP на сервере.
3. **Auth.js / Clerk** — вход, привязка данных к пользователю.
4. Миграция стора: заменить `localStorage`-persist на серверную синхронизацию (стор уже изолирован, менять только слой хранения).

Для этого понадобятся `DATABASE_URL` и ключи провайдера аутентификации.
