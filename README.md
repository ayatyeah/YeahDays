# YeahDays

**«Tinder твоих действий»** — не habit tracker со списком из 50 задач,
а ежедневная подборка нескольких действий под твоё текущее состояние.

Приложение отвечает на один вопрос:
> Какое маленькое действие сегодня максимально приблизит меня к лучшей версии себя?

---

## Что изменилось в этой версии

| Было | Стало |
|---|---|
| Список задач на главной | **Tinder-колода**: свайп вправо — беру, влево — не сейчас |
| Задача = название + сложность | 7 параметров: category, difficulty, duration, energy, timePreference, impact, why |
| Нет рекомендаций | **Scoring-движок** + backend API под будущий ML |
| 3 стата (Тело/Разум/Дисциплина) | **4 стата**: Сила, Интеллект, Капитал, Стабильность |
| PNG-персонаж + гардероб | **3D-персонаж на Three.js**, тело — функция статов |
| 4 экрана | **5 экранов**: Home, Today, Calendar, Progress, Profile |

### Движок рекомендаций

```
taskScore = goalMatch + timeMatch + difficultyMatch + userHistory + freshness
```

| Компонент | Вес | Что учитывает |
|---|---|---|
| `goalMatch` | 0.30 | приоритеты пользователя + отставание стата + impact |
| `timeMatch` | 0.20 | время суток + бюджет минут |
| `difficultyMatch` | 0.25 | энергия сегодня vs требуемая |
| `userHistory` | 0.15 | принял / отклонил / довёл до конца |
| `freshness` | 0.10 | антиповтор показов |

Каждая карточка показывает **почему** её предложили — это строится
из максимального компонента скоринга.

### Подключение настоящего бэкенда

Контракт уже готов. Переключение — одна переменная:

```bash
NEXT_PUBLIC_ENGINE=remote npm run build
```

Тогда `fetchRecommendations()` пойдёт в `POST /api/recommendations`,
а свайпы начнут писаться в `POST /api/events` (обучающая выборка).
Если сеть упадёт — движок автоматически считает локально, экран
не остаётся пустым.

## 3D-персонаж

Атлетичный мужчина 22–28 лет, полуреалистичная стилизация: чистая
геометрия, матовый графит с лёгким каменно-металлическим откликом.
Не мультяшный и не фотореалистичный.

Анатомия собирается кодом, а не импортируется из GLB — поэтому
пропорции это **функция статов**, и тело растёт непрерывно, а не
переключается между тремя картинками.

### Как устроено тело

Торс — не капсула, а **лофт по профилю** (`LatheGeometry` с
эллиптическим сечением): таз → талия → грудь → плечевой пояс.
Именно здесь живёт V-образность, капсулами её не собрать.

Детализировано: грудные с разделением, пресс 6 кубиков + linea alba +
косые, широчайшие под подмышкой, трапеции, дельты, бицепс/трицепс
(объём смещён по оси), предплечья, квадрицепсы, икры (объём назад-вверх).
Лицо: череп-лофт со скулами шире челюсти, надбровные дуги, глаза,
нос, челюсть, короткие волосы, щетина с 5 уровня.

### Что на что влияет

| Стат | Влияние на модель |
|---|---|
| **Сила** | ширина плеч, объём груди/рук/ног, глубина пресса, разворот рук, осанка |
| **Интеллект** | яркость ядра в груди, глаза, визор после 22% |
| **Капитал** | пояс, золотые полосы после 30%, корона после 55% |
| **Стабильность** | кольца платформы, разворот стоп, устойчивость стойки |

Проверенная V-образность (плечи / талия), измерено по вершинам меша:

```
новичок  lvl1  → V = 1.58
прокачан lvl48 → V = 3.01
```

### Прогресс

Нормализация статов логарифмическая с потолком ~1200 XP: первые
задачи дают заметный визуальный отклик, но тело продолжает меняться
и на 40+ уровне. Новичок слегка сутулится и суше; прокачанный стоит
прямо, шире в плечах, руки разведены объёмом широчайших.

### Анимация

Idle (дыхание, покачивание, перенос веса с ноги на ногу, слежение
за пальцем, пульс ядра, вращение платформы) и празднование
(прыжок + руки вверх + вспышка ядра) при выполнении задачи.
Узлы `torso / head / armL / armR / legL / legR / platform` вынесены
в риг — под ходьбу и тренировку хватит их же.

### Бюджет

| Состояние | Треугольников | Мешей |
|---|---|---|
| Новичок | ~9 300 | 47 |
| Прокачан | ~14 500 | 57 |

MeshStandardMaterial, без текстур, 3 источника света — тянет
мобильный GPU в PWA. При отсутствии WebGL приложение продолжает работать.
