# Иллюстрации для ивента «Подготовка к мидтерму» (Cloud Computing)

Задача для Codex: сгенерировать или сверстать 29 изображений и положить их в
`public/events/cc/` под точными именами ниже. Код уже ссылается на эти файлы
из конспектов (`src/lib/events/cloudComputing/*.ts`, строки вида
`![подпись](/events/cc/имя.webp)`). Пока файла нет, картинка в конспекте не
показывается; как только файл появится — покажется сама, без правок кода.

## Требования к файлам

- Формат **WebP**, качество ~80. Размер **1200×800** (3:2), допустимо 1200×900.
  Вес до **150 КБ**. Конвертация: `node -e "require('sharp')('in.png').resize(1200).webp({quality:80}).toFile('out.webp')"`
  (sharp уже есть в проекте).
- Стиль: реалистичное фото или чистая предметная иллюстрация на нейтральном
  фоне, без текста поверх картинки (подпись добавляет сам сайт), без
  водяных знаков. Все картинки — в одном стиле.
- **Без логотипов брендов.** Где в описании упомянут бренд (Netflix, Google),
  рисовать сам предмет без логотипа: например, у сервера Open Connect —
  красная передняя панель без надписи.
- **Без узнаваемых лиц.** Где в описании есть люди (операторы мейнфрейма,
  команда у доски) — снимать со спины, издалека или размыто.
- Только сгенерированные или свободно лицензированные материалы
  (CC0 / Unsplash License).
- **Скриншоты консолей и терминалов** (`*-console*`, `*-wizard*`,
  `*-picker*`, `*-rules*`, `*-terminal*`, `*-manager*`, `*-form*`,
  `*-resource-map*`, `*-dashboard*`) — не генерировать: текст на
  сгенерированных «скриншотах» выходит нечитаемым. Сверстать похожий экран
  в HTML (нейтральная тёмная или светлая консоль, без логотипа AWS/Oracle)
  с теми надписями и значениями, что в описании, и снять его через Playwright.
  Терминал с `docker images` можно снять и настоящий.

## Как проверить

1. Положить файлы в `public/events/cc/`.
2. `npm run dev`, открыть `/events/cloud-computing-midterm`, зайти в
   соответствующую часть — картинка появляется под нужным абзацем с подписью.
3. `node -e "for (const f of require('fs').readdirSync('public/events/cc')) console.log(f, require('fs').statSync('public/events/cc/'+f).size)"` — все файлы до 150 КБ.
4. Коммит: `feat(events): иллюстрации к ивенту по облакам` — только файлы в
   `public/events/cc/`, код менять не нужно.

Если какую-то картинку сделать не выходит — пропустить: конспект без неё
выглядит нормально, просто без фото.
