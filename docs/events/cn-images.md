# Иллюстрации для ивента «Подготовка к мидтерму» (Computer Networks)

Задача для Codex: сгенерировать или подобрать 14 изображений и положить их в
`public/events/cn/` под точными именами ниже. Код уже ссылается на эти файлы
из конспектов (`src/lib/events/computerNetworks/*.ts`, строки вида
`![подпись](/events/cn/имя.webp)`). Пока файла нет, картинка в конспекте не
показывается; как только файл появится — покажется сама, без правок кода.

## Требования к файлам

- Формат **WebP**, качество ~80. Размер **1200×800** (3:2), допустимо 1200×900.
  Вес до **150 КБ**. Конвертация: `npx sharp-cli -i in.png -o out.webp -f webp -q 80 resize 1200`
  или `node -e "require('sharp')('in.png').resize(1200).webp({quality:80}).toFile('out.webp')"`
  (sharp уже есть в проекте).
- Стиль: реалистичное фото или чистая предметная иллюстрация на нейтральном
  фоне, без текста поверх картинки (подпись добавляет сам сайт), без
  логотипов брендов и водяных знаков. Все картинки — в одном стиле.
- Без лиц людей. Без материалов с ограничениями по лицензии: только
  сгенерированные или свободно лицензированные (CC0 / Unsplash License).
- Два скриншота (терминал и Wireshark) лучше сделать реально: открыть
  программу или сверстать похожий экран и снять его, чем генерировать —
  текст на сгенерированных «скриншотах» выходит нечитаемым.

## Список

| Файл | Что на картинке | Где используется |
|---|---|---|
| `network-media.webp` | Три среды передачи рядом: медный UTP-кабель с RJ-45, оптоволоконный патч-корд (жёлтый или оранжевый), небольшая Wi-Fi-антенна. Нейтральный фон. | Лекция 1, часть 1 |
| `data-center-racks.webp` | Ряд 19-дюймовых серверных стоек в дата-центре, холодный синий свет, индикаторы. | Лекция 1, часть 2 |
| `console-cable.webp` | Голубой консольный кабель Cisco (rollover) с RJ-45, подключённый к порту CONSOLE на коммутаторе; второй конец — USB или DB-9. | Лекция 1, часть 3 |
| `putty-terminal.webp` | Скриншот терминала (PuTTY или любой): видны строки `Switch>`, `Switch> enable`, `Switch#`, `Switch# configure terminal`, `Switch(config)#`. Тёмный фон, моноширинный шрифт. Сверстать в HTML и снять — нормально. | Лекция 1, часть 3 |
| `home-router-ports.webp` | Задняя панель домашнего Wi-Fi-маршрутизатора: антенны, 4 жёлтых порта LAN, 1 синий порт WAN/Internet, разъём питания. | Лекция 3, часть 1 |
| `ethernet-nic.webp` | Сетевая карта PCIe с портом RJ-45 крупным планом. | Лекция 3, часть 1 |
| `utp-pairs.webp` | Зачищенный UTP-кабель: видны четыре витые пары (оранжевая, зелёная, синяя, коричневая, с бело-полосатыми парами), рядом разъём RJ-45. | Лекция 3, часть 2 |
| `stp-coax.webp` | Срез экранированной витой пары с фольгой и оплёткой рядом со срезом коаксиального кабеля (жила, изоляция, оплётка, оболочка). | Лекция 3, часть 2 |
| `fiber-connectors.webp` | Три оптических разъёма крупно: ST (круглый байонетный), SC (квадратный), LC (маленький, сдвоенный) на жёлтом и оранжевом патч-кордах. | Лекция 3, часть 3 |
| `wireless-ap.webp` | Потолочная точка доступа Wi-Fi (белый диск с индикатором) на потолке аудитории или офиса. | Лекция 3, часть 3 |
| `hub-vs-switch.webp` | Старый 8-портовый Ethernet-концентратор рядом с современным управляемым коммутатором. | Лекция 4, часть 1 |
| `mac-address-label.webp` | Наклейка на нижней панели сетевого устройства с полем MAC и адресом вида `00:1A:2B:3C:4D:5E` (адрес можно любой, но в этом формате). | Лекция 4, часть 3 |
| `switch-front.webp` | Передняя панель 24-портового коммутатора: порты RJ-45 в два ряда, зелёные индикаторы, пара SFP-слотов. | Лекция 4, часть 4 |
| `wireshark-icmp.webp` | Скриншот Wireshark с фильтром `icmp` в строке фильтра и чередующимися строками `Echo (ping) request` / `Echo (ping) reply`. Реальный захват `ping 8.8.8.8` — лучший вариант. | Сверх слайдов, часть 2 |

## Как проверить

1. Положить файлы в `public/events/cn/`.
2. `npm run dev`, открыть `/events/computer-networks-midterm`, зайти в
   соответствующую часть — картинка появляется под нужным абзацем с подписью.
3. `node -e "for (const f of require('fs').readdirSync('public/events/cn')) console.log(f, require('fs').statSync('public/events/cn/'+f).size)"` — все файлы до 150 КБ.
4. Коммит: `feat(events): иллюстрации к ивенту по сетям` — только файлы в
   `public/events/cn/`, код менять не нужно.

Если какую-то картинку сделать не выходит — пропустить: конспект без неё
выглядит нормально, просто без фото.
