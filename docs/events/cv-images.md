# Иллюстрации для ивента «Подготовка к мидтерму» (Computer Vision)

Задача для Codex: сгенерировать 12 изображений и положить их в
`public/events/cv/` под точными именами ниже. Код уже ссылается на эти файлы
из конспектов (`src/lib/events/computerVision/*.ts`, строки вида
`![подпись](/events/cv/имя.webp)`). Пока файла нет, картинка в конспекте не
показывается; как только файл появится — покажется сама, без правок кода.

## Требования к файлам

- Формат **WebP**, качество ~80. Размер **1200×800** (3:2), допустимо 1200×900
  или 1200×600 для широких композиций. Вес до **150 КБ**. Конвертация:
  `node -e "require('sharp')('in.png').resize(1200).webp({quality:80}).toFile('out.webp')"`.
- Стиль: чистая иллюстрация или реалистичное фото на нейтральном фоне, **без
  текста** на картинке (подпись добавляет сайт), без логотипов и водяных
  знаков, без узнаваемых лиц. Все картинки — в одном стиле.
- Описание в таблице — точный состав кадра: важно то, что на нём видно (например,
  одна и та же сцена под тёплым и холодным светом), а не художественность.
- Схемы с числами (оси, шаблоны классов) рисовать без цифр и подписей — числа и
  объяснение есть в тексте конспекта.

## Как проверить

1. Положить файлы в `public/events/cv/`.
2. `npm run dev`, открыть `/events/computer-vision-midterm`, зайти в нужную
   часть — картинка появляется на своём месте с подписью.
3. Все файлы до 150 КБ.
4. Коммит: `feat(events): иллюстрации к ивенту по Computer Vision` — только
   файлы в `public/events/cv/`.

Если какую-то картинку сделать не выходит — пропустить: конспект без неё
выглядит нормально.
