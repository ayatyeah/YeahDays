Аян: Роутер не принимает команду. Я уже сказал пожалуйста. Ему нужен enable?

Порт Петрович: В Cisco IOS всегда смотри на приглашение. R1 со знаком больше — user EXEC. Команда enable переводит в privileged EXEC, где появляется решётка. Configure terminal открывает глобальную конфигурацию. Команда interface переводит в настройку интерфейса; line console или line vty — в настройку линии доступа. Exit возвращает на один уровень, end или Control Z — сразу в privileged EXEC. Знак вопроса показывает контекстную справку, Tab дополняет команду. Если команда не принимается, сначала проверь режим и имя интерфейса.

Арпи: Перезагрузил станцию. Она забыла настройки. У нас с ней одинаковая память перед экзаменом.

Порт Петрович: Running-config находится в RAM: настройки действуют сразу, но оперативная память теряется при отключении питания. В RAM также находятся ARP-кэш и таблица маршрутизации. Startup-config хранится в NVRAM и используется при загрузке. Во Flash обычно лежит образ IOS. Представь, что настроил адрес и всё заработало, но после перезагрузки настройки исчезли. Причина проста: рабочую конфигурацию не сохранили. Команда copy running-config startup-config копирует её в стартовую.

Аян: Петрович, пароль из вашего имени и трёх восклицательных знаков считается крепким?

Порт Петрович: Начинаем с имени устройства: hostname R1. Enable secret задаёт секрет для привилегированного режима. Banner motd выводит предупреждение при входе. Для консоли переходим в line console 0, задаём password и включаем проверку командой login. Exec-timeout пять ноль завершает неактивный сеанс через пять минут. Значения в угловых скобках — placeholders, их надо заменить. Service password-encryption в классическом IOS скрывает подходящие открытые пароли слабой обратимой Type 7. Это не стойкое хранение секретов и не шифрование сетевого трафика.

Аян: Кабель подключил. Адрес назначил. Интерфейс всё равно обижается и лежит.

Порт Петрович: Выбираем реальный интерфейс устройства. Description добавляет комментарий, ip address назначает IPv4 и маску, ipv6 address — IPv6 с префиксом. No shutdown снимает административное отключение. Само по себе это не гарантирует связь: нужен исправный канал и согласованная настройка другого конца. Команда ipv6 unicast-routing включает пересылку IPv6 между интерфейсами. После выхода сохраняем конфигурацию. На L2-коммутаторе адрес управления обычно задают на SVI, например interface vlan 1, а шлюз — ip default-gateway 192 точка 168 точка 10 точка 1. Это не превращает L2-коммутатор в маршрутизатор; для активного SVI также нужны соответствующие условия VLAN и портов.

Арпи: Я принёс Telnet. Сара сказала убрать этот прозрачный конверт и настроить SSH.

Порт Петрович: Для SSH недостаточно одной команды. Нужны имя устройства, доменное имя, IP-доступность, локальный пользователь и ключи RSA. После crypto key generate rsa выбери поддерживаемый размер, например 2048 в учебной лаборатории. Ip ssh version 2 включает вторую версию. На VTY команда login local использует локальную базу пользователей, а transport input ssh разрешает SSH. Не забудь таймаут и сохранение. SSH шифрует сеанс удалённого управления, Telnet — нет. Console и VTY — разные линии: настройки одной не заменяют защиту другой.

Аян: Команды ввёл красиво. Можно объявлять победу или сначала действительно проверить связь?

Порт Петрович: После настройки проверь show ip interface brief: адрес и колонки Status и Protocol. Обычно рабочий интерфейс должен быть up up. Для IPv6 есть show ipv6 interface brief. Show running-config показывает текущие команды, show startup-config — сохранённые. Show ip route проверяет маршруты. Ping тестирует достижимость, traceroute помогает увидеть переходы. Практический порядок: проверить интерфейс, адрес и маску, шлюз и маршрут, затем связь. Успешный ввод команд — ещё не доказательство работающей сети.
