Аян: В паспорте восемь групп. Уберу все нули и поставлю два двойных двоеточия. Красота же!

Порт Петрович: IPv6 — 128 бит, восемь групп по 16 бит в шестнадцатеричной записи. Ведущие нули в группе можно убрать. Одну последовательность нулевых групп можно заменить двойным двоеточием. На экране полный адрес превращается в 2001, db8, ноль, abcd, двойное двоеточие, один. Двойное двоеточие нельзя применять дважды: тогда невозможно однозначно восстановить пропущенные группы. В стандартной сокращённой записи выбирают самую длинную нулевую последовательность, а при равенстве — первую.

Арпи: С link-local за границу не пустили. А я ему чемодан собрал.

Порт Петрович: Global unicast — глобальные одноадресные адреса, в учебных примерах обычно диапазон 2000 с префиксом три. Link-local начинается с FE80 при префиксе десять и действует только на одном канале: маршрутизатор его дальше не пересылает. Loopback — двойное двоеточие один. Unspecified, двойное двоеточие без единицы, означает отсутствие назначенного адреса в соответствующих процедурах. Multicast начинается с FF. FF02, двойное двоеточие один — все узлы канала, два — маршрутизаторы. Broadcast в IPv6 отсутствует. Link-local и private IPv4 — разные механизмы.

Аян: Провайдер дал дробь сорок восемь. Сколько кварталов дробь шестьдесят четыре туда влезет?

Порт Петрович: Anycast — один unicast-адрес на нескольких интерфейсах, а доставка идёт ближайшему по метрике маршрутизации. Это не рассылка всем. Теперь префиксы: для обычной LAN используют 64. Первые четыре группы — префикс сети, последние четыре — interface ID. Если провайдер выделил 48, четвёртая группа становится шестнадцатибитным идентификатором подсети. Два в степени шестнадцать — 65 536 разных подсетей с префиксом 64.

Аян: Я спросил шлюз у DHCPv6. Он отправил меня в другое окошко.

Порт Петрович: При SLAAC хост формирует адрес по префиксу из Router Advertisement. RA может сообщать и другие параметры в зависимости от возможностей устройств. В варианте SLAAC плюс stateless DHCPv6 адрес всё ещё формируется самим хостом, а DHCPv6 даёт дополнительные настройки, например DNS. При stateful DHCPv6 адрес выдаёт сервер. Важная ловушка: default gateway обычно узнают из RA, а не из DHCPv6. Router Solicitation запрашивает информацию, RA объявляет её. Перед использованием адреса DAD проверяет, не занят ли он.

Арпи: Все интерфейсы обязаны носить MAC в паспорте? Или бывает нормальная приватность?

Порт Петрович: В методе EUI-64 MAC делят пополам, вставляют FFFE и инвертируют U/L-бит. Но это только один способ: interface ID может генерироваться иначе, поэтому неверно считать, что любой IPv6 раскрывает MAC устройства. Для сосуществования IPv4 и IPv6 есть три подхода. Dual stack — устройство работает с двумя стеками. Tunneling — пакет одного протокола переносится внутри другого. Translation — выполняется преобразование между протоколами. Не смешивай эти определения в тесте.
