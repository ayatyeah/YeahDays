Аян: Пингую себя. Ответил! Всё, весь интернет починен? Сара, почему ты вздыхаешь?

Порт Петрович: ICMP передаёт диагностические сообщения и сообщает об ошибках IP. Он не заменяет TCP и не гарантирует доставку. Ping отправляет Echo Request и ожидает Echo Reply. Так проверяется достижимость конкретного узла и оценивается время туда и обратно, RTT. Ping loopback проверяет локальный стек, а не кабель. Ответ шлюза говорит о достижимости шлюза, но не доказывает, что работает весь интернет или нужный веб-сервис.

Арпи: Проба с TTL один не доехала. Петрович говорит: именно это нам и нужно.

Порт Петрович: Traceroute, а в Windows tracert, отправляет пробы с TTL или Hop Limit один, два, три и так далее. На первом маршрутизаторе значение один исчерпывается, и тот возвращает Time Exceeded. Следующая проба проходит дальше. Так постепенно обнаруживаются промежуточные переходы. Конкретный транспорт проб зависит от реализации. Не делай вывод, что все traceroute используют один и тот же протокол передачи проб.

Аян: В трассировке звёздочка! Я уже вызвал пожарных. Отменять?

Порт Петрович: В IOS в выводе ping восклицательный знак означает ответ, точка — таймаут, U — unreachable. В трассировке звёздочка означает, что ответ на пробу не пришёл вовремя. Узел может исправно пересылать данные, но фильтровать ICMP или ограничивать частоту ответов. Поэтому одна звёздочка не доказывает поломку маршрутизатора. Сравни результат следующих переходов и другие проверки, прежде чем делать вывод.

Аян: По ай пи работает, по имени нет. Видимо, сервер забыл, как его зовут.

Порт Петрович: Диагностика идёт от ближнего к дальнему. Сначала IP-адрес и маска, затем loopback, локальный сосед или шлюз, удалённый IP и наконец доменное имя. Ipconfig показывает конфигурацию, ping — достижимость, tracert — переходы, nslookup — разрешение имён. Если удалённый IP отвечает, а доменное имя не разрешается, проверяй DNS. Если даже шлюз недоступен, искать проблему в далёком веб-сервере рано.

Порт Петрович: Вопрос про ICMP code ноль без типа неоднозначен. В ICMPv4 type три, code ноль означает network unreachable. Но type ноль, code ноль — Echo Reply, то есть ответ на ping. Число кода имеет смысл только вместе с типом сообщения. В ICMPv6 неизвестный Next Header сообщается через Parameter Problem. Не переноси таблицу значений IPv4 на IPv6 механически.
