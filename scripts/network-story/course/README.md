# Доставить до эндки — полный сезон

9 серий для модулей 8–16 (лекции 5–10). Сценарная основа: полный русский конспект `src/lib/events/computerNetworksEndterm/notes.json`, а не краткие карточки. `src/lib/events/computerNetworksEndterm/story-coverage.json` связывает каждый раздел конспекта с главами и фиксирует хэш исходного текста. Команды и числовые таблицы присутствуют в кадре; реплики объясняют их смысл. `supplements.json` дополняет примеры TCP/UDP.

Аян — импульсивный курьер; Порт Петрович — инспектор и наставник; Арпи — слишком громкий помощник; Сара реагирует на их приключения. Сезон проходит через доставку, поиск соседа, ремонт роутера, расселение кампуса, IPv6-паспорта, диагностику, транспортное депо, службы приложений и защиту города. Иллюстрации имеют объёмный стиль; ролики собраны программной 2D-анимацией, это не полноценные 3D-модели.

## Производство

- `lessons.json`: полные объяснения, точные подписи и визуальные примеры.
- `dialogues.json`: новые комедийные реплики; `prepare.mjs` составляет сцены.
- `voice.mjs`: ElevenLabs Flash v2.5 с таймкодами и кэшем. Старые объяснения используют существующую запись голоса Петровича. Новый синтез нужен только для новых реплик. Ключ читается локально и не включается в сайт.
- `stage.js`: персонажи, движения, рот по амплитуде голоса, предметы, маршруты, консоль, субтитры.
- `render.mjs`: Chromium canvas → ffmpeg, 1280×720, 15 fps, H.264. `render-all.sh` добавляет звук и смех без перекрытия следующей реплики.
- `package.mjs`: MP4, постер, VTT, текст диалогов и клиентский манифест.
- Фоны: `../assets/{checkpoint,workshop,plaza,depot}.png`; точные запросы для новых локаций — `../assets/season-prompts.json`. Оригинальные изображения сохранены отдельно в каталоге генератора.

Воспроизведение после подготовки кэша:

```sh
node scripts/network-story/course/prepare.mjs
# Только если нужен синтез отсутствующих реплик: расходует ElevenLabs credits.
for m in $(seq 8 16); do node scripts/network-story/course/voice.mjs output/network-season/m$m/script.json output/network-season/m$m; done
seq 8 16 | xargs -P 3 -I '{}' bash scripts/network-story/course/render-all.sh '{}'
node scripts/network-story/course/package.mjs
```

`render-all.sh` использует локальный Python с numpy; путь к нему при переносе окружения необходимо заменить. Готовые MP4 работают без ElevenLabs, Gemini и браузерного синтеза речи. Предыдущий короткий MTU-пилот сохранён отдельно. Старые черновые слайдовые фильмы в сезон не включены.
